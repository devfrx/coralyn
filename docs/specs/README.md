# Specs di progettazione

In questa cartella tengo gli **spec di design** dei moduli, che produco dal processo di
brainstorming prima dell'implementazione.

Convenzione di naming che uso: `YYYY-MM-DD-<topic>-design.md`.

Il flusso che seguo per ogni modulo: **brainstorming → spec (qui) → piano di implementazione →
implementazione**. Le decisioni architetturali che emergono durante uno spec le promuovo
ad [ADR](../architecture/decisions/).
