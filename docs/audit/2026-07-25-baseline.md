## Regola di verifica post-fix

Un fix è verificato solo se: la suite dell'area toccata resta ai numeri della **tabella più
recente**, il typecheck resta exit 0, e il lint non SALE sopra 0 errori (scendere è un
miglioramento, salire è una regressione).
